
## Stack

- Backend: NodeJS + Fastify + Prisma
- Frontend: NextJS (versão 14: Server Components/Actions)

- Permissions: development without being tied to a specific tool, but should be
in ecossysytem javascript.
- Monorepo: architecture for to maintain all the packages and applications in
a same repository (for squad fullstack)
- Workspaces: working with a same dependencie for front and back (eazy manipulation
of dependencies)
- Turborepo: is tool for accelerate processes of monorepo. Example: command "build", being using how convert ts for js, detect only the files that are changed and generate
build. System cache is complete, allow load values.
- Software as Service (SaaS): cant be using by severals companies.
- RBAC: Permission (to put permissions by cargo)
